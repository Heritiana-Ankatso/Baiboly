Optional downloads for the Baiboly app: the reading texts other than Malagasy 1865, the Hebrew and Greek text (STEPBible) and the commentaries. The app downloads one of these files only when the user taps it (Settings › Bible › Downloads, the translation menu, the Study panel).

This is a **pre-release** on purpose, so the app's update check never offers it as an app update. Each file is gzipped SQLite. `packs.json` lists the size and SHA-256 of each file; the app carries its own copy and refuses a file that does not match it.

Sources and licences: see `docs/data-licences.md` in the repository. Some texts are CC BY-SA 4.0 (Saontsin’ Añahare, néo-Crampon Libre, Literal Standard Version) and the Hebrew and Greek data is CC BY 4.0 (STEPBible). The attribution is shown in the app's About screen.

Do not delete this release: versions of the app that know this data set download from it.
