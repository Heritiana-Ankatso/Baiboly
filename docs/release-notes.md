## Baiboly 1.2.0

**Install:** download the APK below and open it on the phone (allow installing from this source when asked).
Updates install over the app and keep your lists, notes, highlights and settings.

* A new look: vellum and ink by day, warm black and gold by night.
* Theme and language (Malagasy, French, English) one tap away.
* Catholic Bibles (73 books): Crampon 1923, néo-Crampon Libre, World English Bible Catholic Edition, Douay-Rheims.
* Literal Standard Version (English).
* Cross-references for every verse; Bible dictionary, topics and the French Martin glossary.
* Offline map of Bible places.
* Reading aloud, also with the screen off (switch it on in Settings); each text is read only with a voice in its own language.
* Study symbol: א for the Old Testament, α for the New.

**Note for users of earlier test builds:** those were signed with a temporary key. To move to this release once: open *Fitahirizana* (Backup) and export a backup, uninstall the old app, install this one, then restore the backup. From this release on, updates install directly.
